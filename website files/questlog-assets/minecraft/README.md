# Minecraft Texture Reference Assets

This folder contains local Minecraft `1.21.1` client texture PNGs extracted from:

`%APPDATA%/.minecraft/versions/1.21.1/1.21.1.jar`

The website uses these local files for editor previews only. Do not treat them as Questlog assets or redistribute them separately from a valid Minecraft installation without checking Mojang/Microsoft asset terms.

`website files/minecraft-texture-index.js` maps common `minecraft:*` item and block IDs to these texture files for quest, objective, reward, and chapter preview icons.
